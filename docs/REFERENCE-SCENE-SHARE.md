# Versioned built-in farm layout sharing

FF2 original-map codes remain unchanged. FF3 codes contain only the fixed reference revision, farm identifier, season, one known greenhouse-ground transition flag, and item type/position/orientation tuples. Exact comparison with bundled base or supported transformed reference terrain is required before sharing. Custom/modified terrain is rejected; local JSON is the alternative. No save payload, screenshot, player/farm names, map arrays, room layouts or original object IDs are encoded. Outdoor layouts are public to anyone receiving a link. Reconstruction uses only bundled data and the normal plan validator; no backend or network storage is needed. All eight starter layouts, four greenhouse transitions, legacy codes and rejection cases are covered by tests. No game-version or commercial permission claim.
