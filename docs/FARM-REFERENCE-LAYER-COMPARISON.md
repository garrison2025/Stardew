# Same-source farm comparison
The eight pinned base restriction masks are now presented with separate access/build/till views and a sortable same-source table. This fixes the previous combined visualization where a blocked access flag could hide independent buildable/tillable flags. The old Wiki estimate table remains distinct. All percentages use the complete map grid; counts can overlap and are not usable acreage, exact in-game terrain, or commercial approval. Unit and browser regressions cover all eight maps and layer-switch/navigation. The private V2.0 task groups for farm types, maps, layouts and named farms remain pending individual reclassification; no keyword or approval counts changed in this PR.
