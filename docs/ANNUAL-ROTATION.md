# Outdoor annual rotation optimizer
Single-tile dynamic programming enumerates legal warm-season planting and harvest schedules, including optional clearing after each regrowth harvest, then removes cost/profit-dominated schedules. With all seeds reserved upfront, identical tiles and unlimited assumed shop stock, the portfolio DP is exact when under the operation cap; otherwise deterministic greedy alternatives are compared against a relaxed upper bound. Winter Powdermelon is independent: owned seed supply, 7-day growth, no acquisition expense. Fixed quality, normal growth, raw sales, no fertilizer, no reinvestment or processing in this model. Existing protected cash-flow scenario is unchanged. Synthetic tests, not independent game fixtures. No new routes or indexability changes.
