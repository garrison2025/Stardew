# Preview feature accuracy

- Map layouts remain independently authored practice maps. Private screenshot calibration and terrain JSON are the path for player-supplied geometry. No game map assets or layout data are distributed. Regular scarecrow coverage is a separate planning layer. It deduplicates overlap and clips the 248-cell radius to map edges. See https://stardewvalleywiki.com/Scarecrow .
- The crop model supports a second season for crops shared by both seasons. It retains the single-crop-per-tile constraint. Growth treatments use an explicitly entered duration and cost for one selected crop. Quality is a fixed sale-price scenario, not a probability forecast. The cash ledger includes fertilizer on the planting date and uses the same harvest schedule and quality. Machine scheduling continues to use greedy assignments and whole-day timing.
- The PC 1.6.15 geode reference is experimental. Source: https://github.com/MouseyPounds/stardew-predictor/blob/master/stardew-predictor.js source blob `f84c2b30a32a04c3485ddabfba2be57cb0cde596`. See MOUSEYPOUNDS-LICENSE.txt. Three input cases × 100 slots × five containers matched the source logic when evaluated separately. Those are software comparisons. Independent in-game captures are still required. Public preview uses example IDs only. Real identifiers are optional inputs in the separate private build and are never stored by the predictor.
- The private Perfection panel reads summary counts from the local collection trackers, including merged save observations. Counts are treated as known minimums unless a category is full. Explicit manual inputs remain separate. Main-player only, no aggregate multiplayer verification.
