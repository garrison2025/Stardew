# Touch and environment preview
Touch is handled separately from mouse editing. Single touch tap applies the active tool on release, single drag pans except explicit rectangle tools, two fingers cancel pending edits and zoom/pan around midpoint, subsequent fingers cannot commit a pending edit. Mouse editing retained. Zoom .08–5; touch geometry tested with synthetic browser touch events and pure math. Dedicated transparent overlay draws bounded water ripples, drifting motes, rain or snow; optional animation defaults off, reduced motion and offscreen visibility stop the animation loop, hidden documents skip drawing. Weather is a visual preview, not game simulation or a saved project field. No remote assets or paid dependencies, no changes to plan schema, data or SEO release gates. PNG export retains existing static lighting but excludes transient effects. Real device testing and commercial rights remain pending.
