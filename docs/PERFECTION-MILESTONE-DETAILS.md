# Per-villager and Stardrop observations
Sources: https://stardewvalleywiki.com/Perfection ; https://stardewvalleywiki.com/Friendship ; https://stardewvalleywiki.com/Stardrop ; pinned Checkup reference in existing milestone parser. Preserve fixed-order 34 standard NPC point values and seven known flag booleans; unknown and duplicate NPC records remain null. Old count-only records remain valid, detail arrays are optional and validated against their totals. No player names, raw mail flags, relationship history or save XML retained. Observations are read-only, individually selectable for recognized players. Public shows references without reading local records. Stardrop false flags mean not confirmed, not confirmed missing. Reference thresholds are 2000/2500, not a relationship simulator. Tests cover consistency, invalid arrays, duplicates, legacy and public item counts. Real-game fixtures remain pending.
