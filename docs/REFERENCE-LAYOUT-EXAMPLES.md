# Eight farm-specific editable reference designs
The original four schematic practice examples remain unchanged. Eight additional layouts start from the existing pinned base terrain and starter marker references, then use deterministic placement validation for crop blocks, scarecrows and selected production markers. Each block must be watered and protected in the model before acceptance; no actual game crop, dynamic obstacle, construction affordability, work route or ownership is inferred. Early expansion does not mean day-one availability. Reference designs are not community-submitted farms, optimal layouts or exact game geometry. Tests cover all eight, conservation of starter markers, placement and coverage; a failed generation is surfaced without replacing the current scene.

The selected example preview uses the existing original-art renderer at thumbnail resolution, only when expanded. It lists modeled crop coverage and added base building costs, excluding starter markers. Farm comparison links load an example on the public preview, but only preselect it in the private workspace; private data is never replaced by a query parameter. The explicit Load button retains confirmation and Undo.
