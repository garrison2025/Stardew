# Positive backpack inventory observations

Structural reference: https://github.com/scriptsforweirdos/stardewsavestructures/blob/master/mp_1_6_architecture.txt (direct player/items/Item with itemId, quality, stack) and https://stardewvalleywiki.com/Modding:Items (qualified object IDs). Only recognized standard ordinary objects in the selected player's backpack are retained, grouped by ID and quality. No raw XML, user names or arbitrary item descriptions. Unmapped/invalid slots are counted; missing data is unknown. Host merge uses existing per-farm binding and transaction. Material prefill matches exact existing ingredient names only and requires confirmation; no generic groups, chest or other inventories. Fair prefill matches the eight existing samples only, preserves quantities and quality, requires actual positive price input. No automatic use of sale values or claims of whole-farm inventory. Backup decode validates the new optional observation field. Synthetic tests only; actual game fixtures are still required.
