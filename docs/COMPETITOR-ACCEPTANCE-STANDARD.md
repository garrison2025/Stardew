# Competitor-aligned reference acceptance — owner scope revision, 2026-11-28
This supersedes the earlier requirement for exhaustive official-grade game certification as a condition of *development completion*. It does not grant intellectual-property rights or approve monetization. Keep the existing 16 routes. No new tools merely to eliminate a partial keyword count.

| Scope | Public benchmark | Practical acceptance |
|---|---|---|
| Farm planning | https://v3.stardew.info/ and https://github.com/StephenFluin/starplan/tree/7ee52554a2e48f47a9d99e256830d7b1b2e5954f | All eight pinned restriction masks, stable coordinates, modeled starter objects, editable plan, local save import and explicit unsupported placements. ## Explicit disposition
- Development completion is evaluated for supported reference scope, exact candidate CI and live deployment. Exhaustive 1.6.15 gameplay fixtures and a perfect editable import of the pinned 1.6.8 sample are not required to call reference development complete. Existing structural fixture, known limitations and any real-game discrepancies remain documented.
- Keyword coverage is task-intent coverage, not exact gameplay equivalence or guaranteed search rank; update only after inspecting the original task and implemented feature. Do not bulk promote the remaining 35 terms just by changing the policy.
- Commercial release is separate. The current flags still represent **unconfirmed** rights/data/fixtures/SERP under the existing production guard; do not set them to true from this decision. Before enabling a production build, reconcile the guard with the documented scope and evidence, ensure actual domain and privacy compliance, and obtain an appropriate legal review of any unresolved game-derived reference pack. Ads stay off.
- Automated viewport/engine tests are sufficient for reference development scope, but actual mobile-device UX and production performance should still be checked before claiming that compatibility.
- No claim that official artwork, Starplan-derived data or Wiki expression is freely available for ad-supported use. The official FAQ is limited to video monetization.
