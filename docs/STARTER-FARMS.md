# Initial farm structures

Eight starting layouts use the documented footprint offsets and coordinates from Starplan's pinned source (https://github.com/StephenFluin/starplan/blob/7ee52554a2e48f47a9d99e256830d7b1b2e5954f/src/app/core/plan/default-buildings.ts and farms.generated.ts). Farmhouse and greenhouse use +4 rows from sprite anchor, not the roof position. Each farm starts with farmhouse, greenhouse, shipping bin and pet bowl. Meadowlands also starts with a coop, gate and 32 fence tiles. The known Beach farmhouse footprint at (59,12) has exactly one base unbuildable but accessible cell (64,16), allowed solely for that specific building and position; boundary, terrain and other-object collision remain checked. No claim that other blocked cells can be built on. Gate uses original fence art, not a game sprite. Dynamic building ground changes, actual game patch and rights remain pending. Start farm and Start empty are separate options; Undo and scene validation preserve both.
