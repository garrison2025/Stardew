# Outdoor machine placement markers
Eight outdoor machine markers with independently authored procedural icons, plus mappings for existing Bee House, Scarecrow and Deluxe Scarecrow. Stable big-craftable IDs cross-checked against Stardew Valley Wiki 1.6.15 recipe output IDs. Exact namespace and recognized class only; reject contradictory qualified IDs. A running recognized production machine can retain its one-tile layout marker even with held products, but no product, processing timer, machine inventory or attachment is decoded. Sprinkler attachment rejection remains unchanged. Synthetic XML tests do not establish full game compatibility. No asset permission or release change.
