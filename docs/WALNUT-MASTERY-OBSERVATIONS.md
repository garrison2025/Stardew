# Walnut, mastery and bundle inventory observations

Golden walnut mapping uses factual internal keys from https://github.com/MouseyPounds/stardew-checkup (MIT license already retained), and task meanings from https://stardewvalleywiki.com/Golden_Walnut. Ambiguous bridge/grove/forge matches are intentionally omitted; first/second labels follow source order where otherwise indistinguishable. Only positive explicit markers and valid limited-drop counters, clamped to task counts, are merged into manual checklist. No negative inference, purchases or whole-farm guarantee. MasteryExp source: https://stardewvalleywiki.com/Modding:Stats; effects reference https://stardewvalleywiki.com/Skills. Existing backpack stock is shown per saved bundle slot by exact ID and qualifying quality; not reserved or summed across competing requirements. Synthetic regressions only. No release gate changes.
