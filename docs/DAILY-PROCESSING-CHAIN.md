# Daily economy processing chain
Fixed planting plan only; greenhouse/annual reinvestment solvers remain distinct. Explicit categories and references: https://stardewvalleywiki.com/Keg , https://stardewvalleywiki.com/Preserves_Jar , https://stardewvalleywiki.com/Dehydrator , https://stardewvalleywiki.com/Mill , https://stardewvalleywiki.com/Cask .
Four shared primary device pools consume raw inventory once; dehydrators need five identical units, mill output counts differ, mill daily input limit is a user assumption for storage/capacity. Primary machine durations round up to morning collections; dried fruit and mill one overnight. Wine enters its own stock ledger and may age in a distinct cellar cask pool (14/28/56 days). Sales arrive next morning; remaining raw stock and unaged wine sell by deadline. No double-counting raw input vs output, capacity and cash assertions; no new dependencies. Greedy scheduling uses positive raw increment, not global optimization; no animal goods, full production chain or exact game clock. Actual game fixtures remain pending.
