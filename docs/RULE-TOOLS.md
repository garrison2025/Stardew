# Reference rules and progress dashboard
Five rule-based tools and private summary replace generic worksheets. References: https://stardewvalleywiki.com/Grandpa , https://stardewvalleywiki.com/Stardew_Valley_Fair , https://stardewvalleywiki.com/Skills , https://stardewvalleywiki.com/Farm_Maps , https://stardewvalleywiki.com/Perfection . Grandpa uses 21-point milestones, fair uses actual price/quality table and category cap, XP/mastery thresholds, eight farm reference counts, weighted perfection with all-or-nothing categories. Perfection is a manual proportional estimate, not exact game rounding/multiplayer; half-skill estimate. Saved progress imports only existing manual records, no raw game XML. Crafting partial counts can be overridden. Private skill and perfection manual storage; no cloud sync. Predictor deliberately remains fail-closed. All routes and noindex/ads release gates retained.
