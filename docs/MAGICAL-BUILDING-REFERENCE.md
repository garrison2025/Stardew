# Magical building catalogue
Six previously missing unique outdoor footprints: Earth, Water, Desert and Island Obelisks, Gold Clock and Junimo Hut. Reference: https://stardew.gs/buildings/ and https://stardew.gs/about/ (reports Steam build 1.6.15.24356). All use 3×2 fixed footprints and separate independent procedural graphics. Build costs are reference base costs, not unlock conditions or actual full collision maps. Save import recognizes exact names and checks stored dimensions. No Junimo harvest simulation, teleportation, Gold Clock effect or game artwork claim. Source is cross-check evidence, not independent in-game fixture or rights approval.
