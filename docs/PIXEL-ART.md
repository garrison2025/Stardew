# Original pixel-art rendering pass
Independent procedural terrain and item sprite engine. Pixel tiles retain 16px native coordinates; data and collision rules are unchanged. Terrain textures use deterministic patch noise, four-side shoreline and cliff edges, inner corners, reeds and foliage; seasonal palette changes are visual. Item sprites are cached by item ID, rotation and season (bounded 512 entries) and reused by canvas, thumbnail, catalog and PNG. Crops have seven silhouettes, building families distinct roof/wall/door details, equipment and paths separate rendering. Coverage overlay now drawn above sprites; placement preview shows actual original sprite. Day/dusk/night are session-only tint previews, not simulation, included in export. No copied game artwork, remote requests or new dependencies. Browser checks compare day/night pixels, count distinct icons and capture screenshots; synthetic fixtures, no real game-map or licensing approval. Original map layouts remain the same.
