## Random extra-harvest expectations (1.6 reference)
Checked all 43 supported crop IDs against the 1.6.15 extracted crop catalogue (juliaramosguedes/stardew-data, 4e0d98119afefd766f15ee77a529db4eb71fa240, data/en-US/crops.json); exactly nine have nonzero ExtraHarvestChance. The repeated-roll expectation is p/(1-p); first item retains its quality distribution and all further items are normal. See https://stardewvalleywiki.com/Modding:Crop_data and https://stardew.gs/about/. Rice's level increment is 0.1 per level and stack data is 1 (https://stardew.gs/crops/unmilled-rice/). The 1.6.8 assembly reference (Dannode36 5225ef409e42a6159a82cf81200bf6eb315c9961) uses inclusive uniform integer sampling, unlike the older Wiki rice description; we model 1 + floor(float32(level*0.1))/2 + 0.1/0.9. At level 0 the estimate is 1.1111, at 10 it is 1.6111. Wiki's 1.6111/2.1111 remains a documented discrepancy, not independently confirmed in 1.6.15 gameplay. Potato expected 1.25; blueberry 3.020408; cranberry 2.111111. Optional UI mode does not include rare luck doubling; backend helper and tests support the reference hand-harvest roll, not scythe crops. No exact RNG, giant crop, by-product, sunflower seed, hay or special game effect validation. Guaranteed planning and inventory are unchanged. 2580 quality/level/crop combinations test isolation from guaranteed planning; not 2580 independent gameplay fixtures.
