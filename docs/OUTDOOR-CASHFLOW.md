# Outdoor cash-flow portfolio comparison
A shared land pool reuses plots across season boundaries; new planting must reach harvest inside its contiguous eligible season(s) and horizon. Finite seed supply, user-defined availability, next-day receipts, conservative per-plant fertilizer charge and shared daily processing capacity. Compares four deterministic planting priorities with and without processing; includes a no-machine fallback. The best tested policy is feasible, not globally optimal. No actual game fixture or new release approval. Existing protected and annual reserved-budget optimizers remain independent.
