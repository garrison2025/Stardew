# Daily economy simulation
Uses existing season optimizer allocation, canonical crop schedule, existing documented processing recipes and linked room access analysis. New planting only, one 28-day outdoor season, optional 0–28 post-season days for processing. Initial cash must cover full planned seed spending; actual purchases debited on planting and replant days. Normal-quality minimum crop harvest. Daily collection and immediate reloading once per modeled day, ceil(recipe minutes / user effective minutes per day), not exact in-game clock. Shared inventory across all recipes; greedy by positive marginal value, no claim of globally optimal processing or crop selection. No batches started that cannot finish by horizon. Raw-only sells daily; processing holds eligible stock and sells nonviable or final stock. End-of-day sales settle next morning; final receivable explicit. Unit and seed conservation asserted. Includes raw baseline, daily ledger, realized sales less seeds and cash; excludes machine construction, labor, fertilizer, additional costs, animals, borrowing, existing inventory, actual save growth stages and multi-season planting. Private farm import aggregates reachable keg/jar counts across linked rooms only, excludes standalone templates. No server, additional dependency, indexing, or rights gate changes. Independent real game fixtures remain pending.
