# Optional linked room sharing
FF2 and FF3 stay compatible and remain default outdoor-only codes. FF4 is generated only with explicit opt-in and at least one linked room. It carries the same pinned reference terrain or original practice revision plus validated room type and tile/device map, not raw object IDs, private screenshots, saves, player/project names or inventory. Invalid room kinds, cells or mismatched buildings fail validation. Codes over 8,000 characters are rejected; JSON retains full layouts. The UI clears generated codes when the sharing scope changes or generation fails. Preview identifies number of linked rooms. No server or game assets required.
