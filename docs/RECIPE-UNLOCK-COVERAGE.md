# Recipe unlock and cooking expansion

Matched all 149 existing crafting names and 81 cooking names to the numerical and unlock condition reference tables at https://stardewvalleywiki.com/Crafting and https://stardewvalleywiki.com/Cooking (2026-11-27). Alternate unlock sources may belong to more than one group. All 81 cooking base sale prices are recorded. Only factual conditions, dates, currency and values; no source descriptions or art. This does not verify all ingredients, output quantities, version differences or actual game unlock flags. Recursive cooking expansion assumes cooking all named intermediate recipes from scratch, with no existing intermediate inventory, and no processing chain beyond the cooking catalogue. Direct inventory and material cost calculation remain separate. No game assets, backend or paid API.
