# Perfection action checklist
Reference comparison: Stardew Checkup (https://mouseypounds.github.io/stardew-checkup/) reports missing goals and detailed still-needed items; stardew.app (https://stardew.app/perfection) connects save observations with individual trackers. Independent implementation using existing catalogs and local positive completion records. Eleven base goal gaps sort by remaining reference points, not by effort or guaranteed gain. Manual count overrides and unknowns remain distinct. The item list covers shipping, fishing, cooking and crafting; never derives individual completion from manual aggregate counts. Only the private workspace reads local records; raw files are not loaded here. No new claims of exact game status, commercial approval, full achievement coverage or SERP ranking.
