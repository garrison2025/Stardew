# Partial private save import
Sources reviewed: https://github.com/scriptsforweirdos/stardewsavestructures/blob/master/mp_1_6_architecture.txt (structural reference; paths inspected, no saves copied), https://stardewvalleywiki.com/Saves , https://zh.stardewvalleywiki.com/Module:Items/en/name/ids (three sprinkler numeric IDs), and the previously documented building dimensions. Independent implementation; no game assets.
Main SaveGame XML only, <=10 MiB, no DTD/entities, <=250k elements and 20k extracted farm records. Parse directly in the private browser, not server-side. Exact 1.6.x version string and a unique top-level GameLocation named Farm required for partial extraction; unsupported versions show structural summary only. Reads root/player version, calendar, farm type, direct farm buildings and object/terrain dictionaries. No account identity, mail, inventory, raw XML, other locations or file contents are persisted. Known building names must match stored footprint, known ordinary sprinkler IDs require object type evidence, attached objects skipped, planted HoeDirt represented as generic crop markers. Unknowns and collisions are reported, not invented. No original terrain inferred; user supplies grid dimensions and manually verifies map. Import preview counts and issue export precede explicit apply; apply replaces objects and clears session screenshot, undo restores layout only. This is not a validated version adapter or full game restore. Synthetic browser fixture and pure model tests are included; independent real-save fixtures still required. No production indexing, advertising or rights gate changes.
