# Private observation dependency split
Separate six rule-tool components while retaining RuleTools compatibility exports. Extract private saved count aggregation and load it only on the existing private workspace refresh path. The same observation decoder and stock validators are now imported inside the existing explicit local observation handlers. No observed data is removed, no parser scope is expanded, and SSR remains unchanged. Shared catalogues and private tracker component imports can still load validation modules; this is a targeted dependency split, not a claim of a fully isolated bundle. Performance improvement must be evaluated on the combined build with route-specific entrypoints using the existing lab audit. No new dependencies or release approvals.
