# Progressive collection rendering
Baseline after route splitting (PR #36): crafting 3500ms, shipping 3411ms, fishing 3253ms, cooking 3208ms mobile-lab hydration. Render up to 32 full interactive cards by default, with Show more, Show all and collapse controls. All search/filter logic, global counts, batch planning, local save and export still operate on the full catalogue. Filter changes reset the display limit; progress state is not stored in individual cards. The complete compact reference names, ingredients and existing hints are server-rendered below the interactive tool so the directory remains readable without JavaScript. No extra page URLs, data removal, dependency, or indexing changes. Browser regression checks initial/full counts, incremental rendering, finding and updating a late entry, and restoring its state after changing filters. Measure new cold-load performance before claiming improvement.
