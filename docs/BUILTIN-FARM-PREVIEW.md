# Built-in terrain reference preview

Source: https://github.com/StephenFluin/starplan/tree/7ee52554a2e48f47a9d99e256830d7b1b2e5954f/public/assets/restrictions (Stephen Fluin). Source blob fingerprints are pinned in compact-farm-identity.ts. The three functional tile flags are transcribed into an independently packed six-bit format and checked against all 52,000 source cells in CI. No source program, game image, TMX or sprite is included. Schematic terrain is drawn by our existing original artwork; gray blocks indicate unavailable cells, not identified water or cliff material. Existing practice maps remain separately available. The preview is not a verified 1.6.15 game adapter. The upstream project is AGPL-3.0-or-later and its game art is expressly non-commercial; do not claim upstream or game commercial data rights have been cleared. This factual-reference experiment remains noindex, ad-free, with all release approval gates unchanged. Before commercial publication, review the specific derived terrain data rights independently of artwork. If needed remove the pack. No external request on use.
