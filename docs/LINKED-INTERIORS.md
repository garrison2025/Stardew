# Linked building interiors and capacity
Outdoor shed/barn/coop/greenhouse objects may have optional validated interior data attached directly to the placed object in schema 2. Old scenes decode unchanged. Room type must match building. Move, copy/paste, undo/redo, saved projects, JSON and project history preserve this data. Deletion removes attached room, undo restores it. Public fragment codes intentionally contain outdoor geometry only; export JSON for full room data. Standalone interior templates remain separate and Big Shed is available there only. Original schematic maps and doors, no actual room-save import. Private saves use existing atomic scene book; all room edits go through outdoor history. Switching to classic editor now retains mounted scene. No new backend or SEO changes.
Processing capacity uses accessible keg/jar counts from committed room layout, one shared raw stock and a user-supplied effective processing-minute window. Supported 18 base crops (excludes wheat special recipe). Wine 3× base/10000m, juice 2.25× base/6000m, jelly/pickles 2× base+50/4000m. Normal output and optionally Artisan +40%; raw quality and Tiller opportunity cost. Integer price rounding, whole completed batches, greedy by positive per-unit value is optimal for this single homogeneous inventory with fixed independent machine capacities. No time-of-day collection, harvest schedule, aging, mixed inventory, capital or labor costs. Increment is sales value over raw sale, not total farm profit. Sources: https://stardewvalleywiki.com/Keg , https://stardewvalleywiki.com/Keg_Productivity , https://stardewvalleywiki.com/Preserves_Jar , https://stardewvalleywiki.com/Wine , https://stardewvalleywiki.com/Juice . Independent numerical implementation, real patch fixtures pending. No official assets.
