## Release procedure
1. Full CI on exact candidate; retain build, coverage, data fingerprint and tests.
2. Confirm both origins using npm run audit:live -- https://stardew-67b.pages.dev https://stardew-local-workspace.pages.dev --revision FULL_SHA. Repeat Lighthouse.
3. Review legitimate actual-game observations, source and rights evidence, exact patch/platform, localized SERPs, real phone/player tasks.
4. Owner-approved preview rollback using both previous successful deployment IDs, audit, roll forward, record actual results.
5. Only after documented rights/data/fixtures/SERP/route approvals select domain, contact and separate app origin, run gated production build. Keep preview mirrors and workspace noindex; ads disabled until independent approval.
