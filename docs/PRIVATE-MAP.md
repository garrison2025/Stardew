# Private screenshot reference and documented irrigation
Game options include a full-map screenshot function: https://stardewvalleywiki.com/Options and https://forums.stardewvalley.net/threads/how-to-share-your-farm-and-use-stardew-planner.152/ . Users may select their own local PNG/JPEG/WebP as a private-session reference, choose map dimensions, calibrate X/Y offsets and tile widths/heights, and manually paint terrain masks. No images are bundled, transmitted, or persisted in JSON/IndexedDB. PNG export can include the user image, subject to the user's own rights. Re-import the screenshot on reopening; terrain mask and placed objects persist separately. The reference image does not infer terrain automatically. This is not a licensed public game asset package or actual save adapter.
Three independently implemented geometric facts (unmodified basic cross 4, quality 8, iridium 24): https://stardewvalleywiki.com/Sprinkler , https://stardewvalleywiki.com/Quality_Sprinkler , https://stardewvalleywiki.com/Iridium_Sprinkler . No copied images, prose or bulk wiki tables. Existing schematic sprinkler IDs retained for backwards compatibility. Tests verify geometry, blocked terrain and occupied non-crop cells. Game patch/platform fixtures, attachments and complete rule integration remain unverified.
Official artwork rights remain separate; wiki about https://stardewvalleywiki.com/Stardew_Valley_Wiki:About . No production gate or SEO configuration changed.

Private rectangle editor accelerates manual local mask painting; entire rectangle rejected if an existing object would become illegal. No game map is automatically reconstructed.

## R7: Data Layers import (local, observed snapshots)
Competitor architecture: https://github.com/hpeinar/stardewplanner/tree/f6c8dd5fba513d78b95d491a8aa77d6532c55ee6/public/planner/js/data/layer-information ; upstream export command and three layer predicates: https://github.com/Pathoschild/StardewMods/tree/f804f7135d3f7c3aa663be9f78187cee0fe2f997/DataLayers . Choose a matching grid, then import exactly one Accessible, Buildable and Tillable JSON file from the same cleared farm/game version. No import of raw game artwork, no server. Strict full-grid coordinate/legend/duplicate validation and independent row-major masks; opaque blocked tiles are not classified as water. An occupied or warp tile stays blocked; building and crop rules are independently checked, generic object placement conservatively uses accessible clear. Import creates a new undoable local scene and optional screenshot alignment; JSON roundtrip preserves masks; public sharing remains original-map only. A snapshot can contain existing buildings/objects/warps: clearing or replacing obstacles requires new exports; no automatic removal or full native game rule emulation. Existing private save import against a snapshot may reject pre-existing occupied tiles. The old competitor files are version-mismatched and not bundled. Exact 1.6.15 data for all eight maps, game artwork authorization, water/cliff classification and beach sprinkler sand restrictions remain unverified. No approval flags changed.

Legacy reference compatibility: independently inspected all 21 files in the pinned V2 commit above, covering seven maps with 44,500 coordinates per predicate (133,500 total). Each file covers the complete expected rectangle with no duplicates or out-of-bounds coordinates. Legacy files sometimes omit empty legend categories; accept only known keys and require every coordinate exactly once. ## Batch compile all eight map packs (maintainer, local only)
The legacy compatibility workflow completed successfully (run 46093650809): 21/21 exports and 133,500 coordinates. The current 1.6.15 map source still needs eight sets of actual game exports. Organize files under a private input directory with folders standard, riverland, forest, hill-top, wilderness, four-corners, beach and meadowlands; in each folder save accessible.json, buildable.json and tillable.json from the same cleared vanilla farm snapshot. Run from the repository root:

```sh
node --experimental-strip-types scripts/compile-farm-data-layers.mjs /private/input /private/empty-output 1.6.15
```

The script validates every coordinate of all 24 files before producing eight standalone map packages and a manifest with hashes, counts and declared version. The 52,000 map positions imply 156,000 layer coordinates. No game files or preview art copied; no network requests. The generated map files are compatible with the existing private terrain import. It refuses a populated output directory. The version and farm identity are caller-declared, not inferred; full rectangle validity does not prove matching game version or permission to distribute. Manifest deliberately keeps versionVerified, baseTerrainVerified, rightsApproved and releaseApproved false. Synthetic eight-map test verifies the entire batch pipeline, not vanilla terrain geometry. Do not commit generated private files. Current external references: https://stardew.gs/maps/farm/tables/ and https://thestardewpedia.com/planner expose 1.6.15 map metadata/planning but no approved downloadable 24-file export was established; modded Meadowlands TMX files are not baseline evidence.
