# Map-first rebuild
Reference: https://stardew.info/ (V3 controls and map-centric UX); https://github.com/hpeinar/stardewplanner (old Apache-2.0 code; README separately credits extracted game art). Independently authored implementation: no source or game sprites copied. V3 is not open source.
The homepage defaults to a Canvas2D layered map editor: cached terrain, object/depth layer, coverage/grid overlay, placement ghost, camera pan/zoom, 24 original illustrative item types, 4 original terrain packs, seasonal palettes, selection/group move, collision/terrain rules, undo/redo, JSON/PNG, local workspace save/import. Classic editor is retained and its project keys are unchanged. Canvas2D chosen instead of WebGL initially for a small dependency-free static build and pixel-art scenes; renderer/model are separate so a texture atlas/WebGL adapter can be added later. Not actual game farm maps or item dimensions. No game asset licensing or release gate changes.
Local custom terrain package: JSON object {id,name,w,h,tiles} with 8–96 width/height, row-major tiles using grass/soil/water/cliff/forest/road. Imported locally only; no external image loading. Actual game-derived assets require separate review and verified version-specific map/placement rules. No real save parsing or cloud collaboration implemented here.
