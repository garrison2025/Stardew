# Field & Farm UI refresh
Sources: Linear March 2026 UI refresh https://linear.app/now/behind-the-latest-design-refresh ; Figma editor anatomy https://help.figma.com/hc/en-us/articles/30925881896727-FD4B-Navigate-Figma-Design-files ; Stardew Planner https://stardew.info/tools/ . These are interaction and hierarchy references, not copied designs or art.
Design: neutral off-white surfaces, forest-green action color, subdued navigation, original inline SVG iconography, one focused workspace. Desktop has persistent grouped navigation and a canvas plus inspector; mobile has a native collapsible navigator, scrollable canvas, stacked inspector. Explicit manual inputs and preview caveats retained; no paid services or remote fonts.
Editor: brush keys 1–5, undo/redo shortcuts, zoom controls, grid/coverage toggles, live coverage statistics, sample layout (manual schematic), confirmed clearing, existing JSON/PNG and workspace import/save. No actual Stardew artwork or rule claims. All sixteen routes share the design system. Crop allocation and checklist progress visualizations show existing computed values only. No new game data or production indexing/ads approval.
