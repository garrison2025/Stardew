# Farm comparison capacity (R31)
Counts use pinned eight Starplan masks and existing modeled starter footprints, not game art or original live geometry. Base clear tillability is access C AND till T/D; base buildability is build B, not necessarily accessible. Deduct the union of modeled footprints from each. Four-neighbor open/reachable counts use the existing farmhouse approach or first clear cell fallback. This is a comparative reference, not guaranteed building legality, complete route accuracy, or actual game clearable/plantable area. Unit tests check eight farms, intersections, footprint deductions and reachability conservation. Browser regression checks all eight rows and sorting. Exact collision, patch validation and rights remain unapproved.
