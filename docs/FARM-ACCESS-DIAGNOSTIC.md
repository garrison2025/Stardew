# Outdoor access diagnostic
Four-neighbor BFS over the reference map. Only path and gate markers are traversable; all other footprints, blocked terrain, occupied and warp flags are conservatively blocked. Start at farmhouse approach if open or the first clear tile, or supply coordinates. Report reachable vs isolated open cells, shortest target steps and building approach/perimeter adjacency. Not exact in-game player/NPC pathfinding, gate state or building doors. No save writes, no external network, no asset permissions changed. Tests cover split grids, gates, row boundaries, invalid coordinates and all eight starter references.
